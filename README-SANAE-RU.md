# Aegisub Sanae — beta 01

Sanae — рабочий форк Aegisub для перевода, редакторской проверки и вёрстки
субтитров. Итоговым форматом остаётся обычный ASS. Исходная дорожка, папки,
статусы и история хранятся рядом в `*.ass.aegisub.json` и не попадают в Text.

## Два рабочих режима

- **Переводчик** — крупные поля оригинала и перевода, предыдущая и следующая
  реплики, поиск и быстрый переход дальше. При наличии подключённой Source-дорожки
  редактируется вся связанная реплика. Без Source сохраняется привычная
  поблочная работа Translation Assistant.
- **Редактор** — вся реплика целиком, контекст с обеих сторон, статусы, история,
  лёгкий QC и защита ASS-тегов/векторных рисунков.

Переключатель находится в верхней строке Translation Assistant.

## Папки

Выделите строки и откройте контекстное меню таблицы → **Папки субтитров**.

- новая папка может быть корневой или находиться внутри другой папки;
- щелчок по заголовку папки в колонке **Папка** сворачивает или раскрывает ветку;
- **Группировать таблицу по папкам** собирает ветки вместе только на экране;
- перенос строк и перенос самой папки выполняются через то же меню;
- удаление папки не удаляет строки ASS.

Цвет текста для фона папки выбирается автоматически: белый на тёмном, чёрный
на светлом.

## Следующая реплика в аудиоматрице

Следующий незакомментированный субтитр всегда показан янтарным диапазоном и
подписью `Следующий: …`. Настройка общего отображения неактивных строк на него
не влияет.

## Русская версия

Windows portable-сборка запускается на русском по умолчанию и содержит каталог
`locale/ru/LC_MESSAGES/aegisub.mo`. Язык можно сменить через **Вид → Язык**;
после перезапуска будет использован выбранный интерфейс.

## Сборка из Git

Ветка `sanae-beta` автоматически собирает Windows portable ZIP и установщик.
Тег вида `sanae-beta-01` дополнительно создаёт GitHub Release. Локальная сборка
остаётся стандартной Meson-сборкой Aegisub.

## Безопасность ASS

Папки, их вложенность, цвета, статусы и история существуют только в sidecar.
Сортировка по папкам не переставляет события ASS. Для релиза обязательно
прогоняется `tools/sanae-ass-integrity.py` и контрольная вшивка сложных строк
с `\\p1`, `{=…}`, цветами, alpha и несколькими слоями.
