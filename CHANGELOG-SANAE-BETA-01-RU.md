# Aegisub Sanae — beta 01

- Windows portable запускается с полным русским интерфейсом по умолчанию; язык
  по-прежнему можно сменить штатной настройкой Aegisub.
- Translation Assistant разделён на два понятных режима: **Переводчик** для
  быстрого перевода по Source и **Редактор** для стилистической правки, статусов,
  истории и QC. Без Source у переводчика остаётся привычная поблочная работа.
- Папки стали вложенными. Ветки можно сворачивать и раскрывать, переносить в
  другие папки и собирать вместе в таблице без изменения порядка событий ASS.
- В аудиоматрице следующий незакомментированный саб всегда показан отдельным
  янтарным диапазоном с подписью `Следующий: …`.
- Сохранены функции предыдущей версии: Source-колонка, связи слоёв один к одному,
  поиск, статусы проверки, история Text, защита ASS-тегов и групповые тайминги.
- Все рабочие метаданные остаются в `*.ass.aegisub.json`; ASS не получает новых
  полей. Добавлен тест целостности `tools/sanae-ass-integrity.py`.
- Добавлен GitHub Actions-процесс для ветки `sanae-beta` и тега
  `sanae-beta-01`: Windows portable ZIP, установщик и GitHub Release.
