# Aegisub Sanae beta 01: чеклист ручной проверки

Проверяйте только на копиях рабочих `.ass`. Новые статусы, папки, связи с оригиналом и история находятся в соседнем `.aegisub.json`; в поля ASS они не добавляются.

## 1. Русский и английский интерфейс

- [ ] Выбрать русский язык штатной настройкой Aegisub и перезапустить программу.
- [ ] Проверить, что на русском отображаются новые режимы Translation Assistant, девять статусов, фильтры, папки, поиск, QC, защита тегов и все сообщения об ошибках.
- [ ] Переключиться на английский и проверить те же элементы.
- [ ] Вернуться на русский: переключается весь интерфейс, а не только новая часть.

## 2. Подключение оригинальной дорожки

- [ ] Открыть перевод `target.ass`, затем в меню инструментов выбрать `Открыть оригинал перевода...` и указать `source.ass`.
- [ ] Убедиться, что `target.ass` не заменился и не изменился.
- [ ] Сохранить, закрыть и снова открыть `target.ass`: оригинал должен подключиться из sidecar автоматически.
- [ ] Выполнить `Закрыть оригинал перевода`: оригинал отключается, перевод остаётся без изменений.

## 3. Большие надписи, векторные рисунки и колонка Source

- [ ] Проверить приложенный пример с несколькими слоями на одинаковом тайминге `0:00:47.03–0:00:54.05`.
- [ ] Для строк с `\p1` в Source должна быть короткая надпись `[векторный рисунок ASS]`, а не тысячи координат.
- [ ] Текст Source не должен рисоваться поверх соседней колонки Text даже при очень длинной строке.
- [ ] Слои надписи с одинаковыми таймингами должны сопоставляться по порядку один к одному, а не получать все исходные слои сразу.
- [ ] Обычный текст Source отображается без служебных override-тегов; сама исходная строка доступна только для чтения.
- [ ] Маркеры `{=188}` и `{=189}` после сохранения должны остаться на месте.

## 4. Режимы «Переводчик» и «Редактор»

- [ ] Без подключённого Source выбрать `Переводчик`: доступна привычная поблочная работа.
- [ ] Подключить Source и выбрать `Переводчик`: редактируется целая связанная реплика, рядом видны оригинал и контекст.
- [ ] Выбрать `Редактор`: редактируется вся реплика, доступны статус, QC, защита тегов и история.
- [ ] Несколько раз переключиться между `Переводчик` и `Редактор`: текст не должен теряться.
- [ ] Закрыть и открыть помощник: выбранный режим должен восстановиться.

## 5. Предыдущая и следующая реплики

- [ ] В новом помощнике видны отдельные блоки предыдущей и следующей реплик.
- [ ] В таблице активная строка имеет обычную рамку, следующая видимая строка — пунктирную рамку и цветную метку слева.
- [ ] При фильтрации и свёрнутых папках подсвечивается именно следующая видимая строка.
- [ ] Подсветка не должна менять выделение, тайминги или порядок строк.

## 6. Поиск

- [ ] Найти часть слова из оригинала и часть слова из перевода — поиск должен работать по подстроке.
- [ ] Повторить поиск разным регистром при выключенном `Учитывать регистр`: результат тот же.
- [ ] Включить `Учитывать регистр`: регистр должен влиять на результат.
- [ ] Теги и координаты рисунков не должны требоваться для совпадения.
- [ ] После последнего результата поиск продолжается с начала.

## 7. Статусы и массовая проверка

- [ ] Проверить все этапы: `Не переведено`, `Черновик`, `Нужен контекст`, `Сомнение OCR`, `Смысл проверен`, `Отшлифовано`, `Тайпсет`, `QC пройден`, `Готово`.
- [ ] Выделить много строк и через контекстное меню таблицы назначить им один статус.
- [ ] Выделить строки с разными статусами и выполнить `Продвинуть статус проверки`: каждая переходит ровно на один этап, `Готово` остаётся `Готово`.
- [ ] Кнопка `Отредактировано + дальше` сохраняет текст, ставит статус и переходит к следующей строке.
- [ ] Каждый фильтр показывает только нужный этап; возврат к `Все` восстанавливает полный список.
- [ ] Сохранить ASS при активном фильтре: скрытые строки не должны удалиться.

## 8. Вложенные цветные папки

- [ ] Выделить слои одной большой надписи и создать из них папку.
- [ ] Выбрать почти чёрный цвет: текст строки должен стать белым.
- [ ] Выбрать почти белый цвет: текст строки должен стать чёрным.
- [ ] Переместить другие строки в существующую папку и удалить часть строк из папки.
- [ ] Создать дочернюю папку, перенести её в другую ветку и убедиться, что циклическое вложение запрещено.
- [ ] Включить `Группировать таблицу по папкам`: строки собираются по веткам только на экране, их исходные номера не меняются.
- [ ] Свернуть родительскую папку: в таблице остаётся первая подходящая строка всей ветки; развернуть — возвращаются строки и дочерние папки.
- [ ] Выбрать папку целиком и убедиться, что выделены все её ASS-строки.
- [ ] Удалить папку: сами строки, их порядок, текст и тайминги остаются.

## 9. Следующий саб в аудиоматрице

- [ ] Выбрать обычную реплику: следующая незакомментированная реплика видна янтарным диапазоном и подписью `Следующий: …`.
- [ ] Выключить показ остальных неактивных строк: следующий саб остаётся видимым.
- [ ] Перейти на последнюю реплику: старый диапазон следующего саба исчезает.
- [ ] Изменить текст или тайминг следующей реплики: диапазон и подпись обновляются.

## 10. История и автосохранение

- [ ] Трижды изменить Text одной строки и открыть `История текста`: доступны предыдущие варианты.
- [ ] Восстановить вариант: меняется только Text выбранной строки, операция доступна для Undo.
- [ ] Дождаться штатного автосохранения Aegisub.
- [ ] Рядом с `*.AUTOSAVE.ass` должен появиться `*.AUTOSAVE.ass.aegisub.json` с историей, статусами, папками и связями.
- [ ] Обычное сохранение и повторное открытие восстанавливают последние 50 вариантов истории.

## 11. ASS-теги и рисунки

- [ ] Оставить включённым `Защищать ASS-теги и рисунки`.
- [ ] Изменить только видимый текст строки с тегами: изменение применяется, теги остаются байт-в-байт прежними.
- [ ] Попытаться удалить или изменить override-тег: изменение блокируется с русским предупреждением.
- [ ] Попытаться изменить строку с `\p1`: изменение блокируется.
- [ ] Открыть инспектор тегов: видны override-блоки, размер векторного блока и количество extradata-ссылок.
- [ ] Отключать защиту только для намеренного тайпсета; после такого изменения отдельно проверить рендер.

## 12. QC и групповые тайминги

- [ ] QC обнаруживает нулевую длительность, высокий CPS, превышение длины, двойные пробелы, несбалансированные скобки, отсутствующий стиль и overlap.
- [ ] Для векторных рисунков не выводятся бессмысленные CPS, длина и двойные пробелы.
- [ ] Проверить команды групповых таймингов из `Тайминг -> Групповые операции`: минимальный зазор, удаление overlap, lead-in/out, сдвиг последующих строк.
- [ ] В preview нажать `Нет`: изменений нет. После применения одного preview один Undo отменяет всю групповую операцию.

## 13. Целостность ASS и вшивка

- [ ] Сохранить копию файла до и после обычного Save без редактирования Text и выполнить:

  `python tools/sanae-ass-integrity.py BEFORE.ass AFTER.ass --strict-text`

- [ ] После редактирования перевода выполнить ту же команду без `--strict-text`: все поля вне Text и extradata-ссылки должны совпасть.
- [ ] Открыть сохранённый ASS в обычном Aegisub и отрендерить тестовый фрагмент тем же способом, которым субтитры вшиваются в аниме.
- [ ] Временно убрать `.aegisub.json`: ASS всё равно открывается и рендерится; исчезают только сервисные статусы, папки, история и Source.
- [ ] Проверить, что в ASS не появились `folder_id`, `status`, `history`, `source_rows` или другие sidecar-поля.
- [ ] Количество, порядок и типы Dialogue/Comment совпадают с ожидаемыми; Layer, Start/End, Style, Actor, Margins и Effect не меняются без явной команды.

## Что приложить к сообщению об ошибке

- Номер пункта чеклиста и точные действия.
- Скриншот окна целиком.
- Минимальные копии `target.ass`, `source.ass` и `.aegisub.json` на 2–10 строках.
- Результат `tools/sanae-ass-integrity.py`.
- Указание, воспроизводится ли проблема после перезапуска и без sidecar.
