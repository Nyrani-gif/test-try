# Обновления из приватного репозитория Sanae

Проверка обновлений обращается к последнему GitHub Release приватного
репозитория `yHdra/aegisubsanae` и сравнивает номер в теге `sanae-beta-*` с
номером, встроенным в приложение при сборке.

Токен не записывается в исходники или `config.json`. На Windows откройте
**Диспетчер учётных данных → Учётные данные Windows → Добавить общие учётные
данные** и создайте запись:

- адрес: `Aegisub Sanae/GitHub`;
- пользователь: произвольное понятное имя;
- пароль: fine-grained GitHub token с доступом только к репозиторию
  `yHdra/aegisubsanae` и правом чтения Contents/metadata.

Программа читает пароль через Windows Credential Manager (`CredReadW`) только
на время HTTPS-запроса к GitHub API. При отсутствии записи автоматическая
проверка завершается без диалога; ручная проверка сообщает, как настроить
доступ.

Кнопка «Скачать» пока открывает asset релиза в браузере, а «Открыть страницу
релиза» — сам Release. Безопасная фоновая загрузка, проверка подписи и запуск
установщика намеренно не реализованы на этом этапе.
